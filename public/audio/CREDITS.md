# Audio policy

No recordings or music tracks are bundled in the current tree. Startup and
interface cues are generated by the project's Web Audio code in
`src/lib/sfx.ts`, covered by the project MIT attribution.

The previous `ambient.mp3`, `boot-music.mp3` and `work.mp3` were removed in the
final publishing pass. Their old credits claimed Kevin MacLeod/CC BY 4.0, but
history shows replacement recordings without corresponding credit updates;
rights to the exact retained recordings could not be verified. This is a
provenance finding, not a conclusion that any particular recording infringed.
See [the asset audit](../../ASSET_AUDIT.md) for details.

Optional private overrides still work with the existing sound modules. Add only
recordings you created or have permission to use. Audio override files are
ignored by Git and are not automatically covered by this project's MIT license.
Do not publish a build containing overrides without verifying their rights and
including any required attribution. Default startup does not enable background
music or a continuous synthesized bed.
